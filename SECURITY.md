# Security policy

## Supported versions

review-loop is pre-1.0. Security fixes are made on the latest released version;
older `0.x` releases are not maintained separately.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Email
[marcus.bransbury@gmail.com](mailto:marcus.bransbury@gmail.com); maintainers
will track accepted reports in a private GitHub security advisory.

Include the affected version, installation method, reproduction steps, impact,
and any suggested mitigation. You should receive an acknowledgement within
seven days. Please allow time for a fix and coordinated release before public
disclosure.
